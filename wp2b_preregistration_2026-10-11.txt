WP2b PRE-REGISTRATION -- 2026-10-11 (frozen before the first table lookup)
=========================================================================

Work package: answer the WP2 k=5 question by table lookup instead of SAT. Knuth
computed the exact minimum Boolean-chain length C(f) over the full binary basis for all
616,126 NPN classes of 5-input functions (TAOCP 7.1.2, program BOOLCHAINS);
apgoucher/optimal5 packages the result as knuthies.dat (616,124 records of 15 bytes;
the two trivial classes, constant and literal, are implicit). The repository is cloned
read-only at /tmp/optimal5 (not copied into this repo; commit hash, URL and licence are
recorded in sources/SOURCES.md).

Question: minimum of C(f) over all 1-stable 5-input functions (GHKK Definition 2, both
signs, transcribed in sources/GHKK_TRANSCRIPTION_2026-10-11.txt); same over weakly
1-stable (Definition 1) and over 2-stable functions; cost histogram of each class.

Nothing in WP2b is a lower bound and nothing here may be described as one: the table
gives exact minima per class (Knuth's exhaustive computation, not re-verified here), and
the minimum over a class of functions is a ceiling statement about the GHKK gadget.

Toolchain note (recorded before running): no C/C++ compiler is installed on this host
(g++, gcc, clang, cc all absent), so human_readable.cpp cannot be built. The pre-
registered alternative is a pure-Python decoder of knuthies.dat that mirrors bytes2gv()
in optimal5.h; it is validated against Knuth's published histogram (checktab.py) before
any use.

Conventions
-----------
- WP1 truth table: integer whose bit t is f on row t, row t assigns x_{i+1} = (t >> i) & 1.
- optimal5 truth table (from optimal5.h, calcs[1..5] = 0x0000ffff, 0x00ff00ff,
  0x0f0f0f0f, 0x33333333, 0x55555555): bit b is f on the assignment
  x_j = 1 - ((b >> (5 - j)) & 1), j = 1..5. The two conventions differ by an NPN
  transformation (reverse the five index bits, then complement the index), so a class
  is a class in both; every per-function value is converted explicitly and the
  conversion is checked on gst1 and on the decoded circuits by simulation.
- Cost convention (Knuth): gates over {AND, OR, XOR, AND-NOT} on a normalised chain;
  constants and literals cost 0; negation is free (absorbed into gate types); the chain
  is for the canonical representative and a negated output is a free final NOT.
  WP1 (B2 encoder): any of the 16 binary gate types; negation is free inside gates but
  a constant output or a negated input as output costs 1 gate (the encoder needs a gate
  node). Expected mismatch therefore exactly on constants and negated literals.
- "stable1" = 1-stable, Definition 2 as printed (|Y| <= 2, both signs); "stable1pos" =
  positive sign only (Appendix A script (i)); "weak1" = Definition 1 (|Y| <= 1);
  "stable2" = 2-stable (|Y| <= 3, both signs). The oracle is stable_check.py (WP2).

What refutes each
-----------------
P1: any verdict change for stable1 / weak1 / stable2 (then the written argument is
    wrong or the checker is not a function of the truth table); no change for stable1pos
    on NOT gst1.
P2: any histogram cell differing from checktab.py, orbit sum != 2^32, or any target
    mismatch other than the 7 listed degenerate rows. A disagreement on a WP1 proof-
    backed row (XOR, AND) would indicate a decoder or convention error; on a glyph-count
    row (MAJ_5, THR2_4, THR3_4) it would be a contradiction of WP1 to report as such.
P3: a stable1 class of cost <= 10 (then the GHKK Corollary 6 ceiling tightens to
    min + alpha, and the argmin circuit must be verified by simulate.py, by
    stable_check.py and by a WP1-encoder SAT run at s = min, never by the table alone);
    a stable2 class at k=5; a weak1 minimum other than 3 / 4.

Metric (read exactly as written in the brief)
---------------------------------------------
(1) Invariance script: per variant, N random NPN transformations per function; output
    = integer count of pairs with different verdicts; 0 = pass.
(2) Decoder: CSV with one row per representative (tt in optimal5 convention, tt in WP1
    convention, n_gates, orbit size, verdicts stable1/weak1/stable2, essential count)
    plus class-per-cost and function-per-cost histograms compared row by row with the
    13 values of checktab.py (exact integer equality); orbit sum == 4294967296.
(3) Convention cross-check: CSV (name, our value, optimal5 cost via NPN-orbit search in
    the representative dictionary, match, note) for the listed targets, the 256 bfs3
    and the 32 sym4 rows; metric = number of mismatches not explained by the 12
    degenerate functions (expected 0) and number of degenerate mismatches (expected
    exactly 7).
(4) Result: min_cost = min(n_gates) over accepted rows per variant; argmin = classes at
    that cost with the decoded circuit (transformed back to the WP1 convention);
    histogram = count per cost (classes and functions). If min <= 10 for stable1 the
    argmin circuit must pass simulate.py, stable_check.py --variant stable1 and a WP1-
    encoder SAT run at s = min (< 60 s); only then is min <= 10 declared.

Constraints: single-threaded; no SAT solving beyond quick (< 60 s) SAT-side checks; the
