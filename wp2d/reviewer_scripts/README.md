# Reviewer scripts (unreviewed, kept for reference)

Produced during the adversarial review of WP2c (2026-10-12) and copied here
verbatim so they survive the ephemeral container. They enumerate circuit
structures with every node in the output cone, normalised gate types and inputs
up to permutation, and test 1-stability with `stable_check.py`. Reported counts:
(6,5) 0 of 29,005 distinct functions 1-stable; (6,6) 0 of 1,857,928;
(7,6) 0 of 437,025; (4,4) and (5,5) also 0.

These scripts are NOT part of any pre-registered work package and were not
independently reviewed. WP2d re-derives the enumeration from scratch and is the
only source for any claim made in the top-level README.
