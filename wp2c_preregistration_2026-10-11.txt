WP2c PRE-REGISTRATION -- 2026-10-11 (frozen before the first control and the first run)
=========================================================================================

Work package: close the gadget question globally.  WP2b established (Knuth's table via
optimal5, validated; confirmed by simulate.py, stable_check.py and the WP1 SAT encoder
with UNSAT at s = 0..6 and SAT at s = 7) that the minimum B2 circuit size over all
1-stable (GHKK Definition 2, both signs) 5-input functions is 7, attained by the class
0x00071357 (monotone AND/OR chain).  WP2 established by exhaustive enumeration that no
1-stable function exists on 3 or 4 inputs.  GHKK Theorem 4 / Corollary 6 make the
ceiling constant equal to gates(g) regardless of the gadget's input count, so the
remaining question is: does any 1-stable function on k >= 6 inputs have <= 6 gates?

What WP2c is NOT: no outcome of WP2c is a circuit lower bound.  The result is a
statement about the plain gate-elimination method with the measure mu_alpha and
1-substitutions (a ceiling on what that method can prove), nothing else.

Conventions (unchanged from WP2 / WP2b)
----------------------------------------
- Truth-table row t assigns x_{i+1} = (t >> i) & 1 (WP1 convention).  A k-input
  function is an integer whose bit t is the value on row t; 2^k rows (64 for k = 6,
  128 for k = 7).  Python integers are unbounded, so 128-bit truth tables are exact.
- "stable1" = 1-stable, Definition 2 as printed (every Y with |Y| <= 2, every y in Y,
  some tau on X \ Y with g|tau == y or g|tau == not y).
- mode full = WP1 symmetry breaking (N normal gates, D no degenerate gates, U every
  gate used, O colex order; S off).  With U the encoding is NOT monotone in s.
  mode none = plain encoding, all 16 gate types, monotone in s.
- essential flag = 0 everywhere (1-stability implies that every input is essential, see
  Argument A; the flag would be redundant).
- TIMEOUT is recorded as TIMEOUT, never as UNSAT.  Hard per-instance timeout 3600 s,
  1 worker (the other core is busy with the WP2 k = 5 ladders, which are not touched:
  results_wp2_k5.csv, results_wp2_k5_min.csv, log_wp2_k5.txt stay as they are).
- Solver: cadical195 via python-sat, as in WP1/WP2.  UNSAT answers are not
  DRAT-certified (same caveat as WP1); the only counter-check of the symmetry-breaking
  mode is the mode-none run of the same instance.

Structural arguments written down before the runs
--------------------------------------------------
Argument A (the brief's bound k <= s + 1).
  (A1) A 1-stable function depends on every one of its inputs.  Proof: take Y = {y}
       (|Y| = 1 <= m + 1 = 2).  Definition 2 gives tau on X \ {y} with g|tau = y or
       g|tau = not y; in both cases g|tau is not constant, so g depends on y
       (GHKK Section 3.1: f depends on x if some restriction of all other variables
       leaves a non-constant function).
  (A2) A function that depends on k inputs needs at least k - 1 gates.  Proof: restrict
       a circuit computing it to the cone of the output node.  Every input the function
       depends on is in the cone (an input outside the cone does not influence the
       output).  The cone is a connected DAG with k + g' nodes and 2 g' edges, where g'
       is the number of gates in the cone (each gate has in-degree 2; inputs have
       in-degree 0).  Connectivity gives 2 g' >= k + g' - 1, i.e. g' >= k - 1, and the
       circuit has at least g' gates.
  (A3) Hence a 1-stable function on k inputs has gates(g) >= k - 1, i.e. a gadget with
       s gates has k <= s + 1.  For s <= 6 this leaves k <= 7.  With WP2 (no 1-stable
       function for k <= 4) and WP2b (minimum 7 at k = 5), the open instances for
       "<= 6 gates" are exactly (k, s) in {(6, 5), (6, 6), (7, 6)}.  The instances
       (6, s <= 4) and (7, s <= 5) are UNSAT by (A3) and serve as sanity rows.

Argument B (tree lemma; my addition, written before the runs, hand-checked only).
  Claim: no function computed by a circuit with exactly k - 1 gates on the k inputs it
  depends on (k >= 2) is 1-stable.  Hence (k, k - 1) is UNSAT for every k >= 2; in
  particular (6, 5) and (7, 6) are UNSAT, and the only instance on which the SAT runs
  carry information beyond the hand arguments is (6, 6).
  Proof.  Let C compute f, f depends on all k inputs, and C has k - 1 gates.  By (A2)
  the cone of the output has g' = k - 1 gates, 2k - 2 edges and 2k - 1 nodes, so it is
  a tree: every node except the output has out-degree exactly 1 (fan-out 1), and the
  cone contains every gate of C.  Every gate op of the cone is non-degenerate (depends
  on both of its arguments): if a gate ignored one argument, the inputs below that
  argument would have no other path to the output (tree) and f would not depend on
  them.  Pick any input x; it feeds exactly one gate G = op(u, x) (either argument
  order).  Let y be an input in the closed cone of u (if u is an input, y = u).  Take
  Y = {y, x}, which has |Y| = 2 <= m + 1, and the element y of Y.  Suppose some tau on
  X \ Y gives g|tau = y or g|tau = not y.  Under tau, u is a function of y alone:
  u|tau in {0, 1, y, not y}.
    - If u|tau is constant, G|tau = op(const, x) is a function of x alone; y reaches
      the output only through G (tree), so f|tau is a function of x alone and does not
      depend on y.  Contradiction.
    - If u|tau = y or not y, then G|tau = op(+-y, x).  Because op is non-degenerate,
      op(a, .) is non-constant for some value a, and +-y takes that value for one value
      of y, so G|tau depends on x.  Above G, every node is a function of G|tau and
      constants only (x feeds only G; y reaches the output only through G), so
      f|tau = F(G|tau) with F : {0,1} -> {0,1}.  If F is constant, f|tau does not
      depend on y; if F is a bijection, f|tau depends on x.  Contradiction either way.
  So Definition 2 fails for (Y, y), and f is not 1-stable.  QED.
  Consistency with existing data: (3, 2), (4, 3) UNSAT in results_wp2_k34.csv (both
  modes), (5, 4) UNSAT in results_wp2_k5.csv (mode full); the exhaustive counts of WP2
  (0 1-stable functions at k = 3, 4) and the WP2b minimum 7 = k + 2 at k = 5 agree.
  Status: a hand proof; the SAT rows (6, 5) and (7, 6) are its mechanical check at
  k = 6, 7.  If either row returns a verified SAT, Argument B is wrong and the SAT
  result wins.

Remark on (6, 6) (no claim): by the count in (A2), a 6-gate circuit on 6 inputs that
depends on all of them has an output cone with 5 or 6 gates; 5 gates is the tree case
(Argument B), 6 gates means a tree plus exactly one extra edge (exactly one node of
out-degree 2).  Whether such a circuit can be 1-stable is decided by the SAT run.
